Stop guessing dimensions in 3ds Max! 📐✨

Smart Dimension is an interactive, high-precision measurement toolkit designed for Autodesk 3ds Max. Whether you need instant bounding boxes, point-to-point distances, closest gap between multiple objects, angles, or 3D polygon area & perimeter, this tool handles it all inside your viewport with full Undo support.

📥 Download Script (Free on GitHub):
https://github.com/mrtvisual/3Ds-max-Smart-Dimension

03:45 - 3D Surface Area & Perimeter Calculation
04:30 - Customization (Markers, Colors, Units: mm, cm, m, in, ft)
05:15 - Installation & Toolbar Docking

---

🛠 Installation:
1. Download the .zip file from the GitHub link above.
2. Drag and drop the .mcr file into your 3ds Max viewport.
3. Open Customize > Customize User Interface > Toolbars.
4. Locate the "mrtTools" category and drag "Smart Dimension" onto your toolbar.
